# Datastraw AI Support Inbox - Client Frontend

This directory contains the React 19 + Vite frontend application for Datastraw Support Inbox.

For complete project documentation, architectural diagrams, end-to-end testing flows, and assessment walkthroughs, please refer to the main [Root README](../README.md).

## Quick Start (Frontend)

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
# Copy .env.example if .env does not exist:
# VITE_API_BASE_URL=http://localhost:5000

# 3. Start local development server
npm run dev

# 4. Compile production build
npm run build

# 5. Run linting checks
npm run lint
```
